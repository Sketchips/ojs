 *

 *    - Size: 1920x600px
 *    - Format: JPG (optimized)
 *    - File size: < 200KB
 *    - Aspect ratio: 16:5
 */

/* ============================================================================
   6. TROUBLESHOOTING - Common Issues
   ============================================================================ */

// ===== Issue 1: CSS Not Loading =====
/**
 * SOLUSI:
 * 1. Clear OJS cache: php tools/rebuildSearchIndex.php
 * 2. Clear browser cache: Ctrl+F5
 * 3. Check file permissions: chmod 644 modern-ojs-theme.css
 * 4. Verify path in template: {$baseUrl}/modern-ojs-theme.css
 */


// ===== Issue 2: JavaScript Errors =====
/**
 * SOLUSI:
 * 1. Check browser console (F12)
 * 2. Ensure jQuery loaded before custom JS
 * 3. Ensure Bootstrap JS loaded
 * 4. Check for conflicts with other plugins
 */


// ===== Issue 3: Carousel Not Working =====
/**
 * SOLUSI:
 * 1. Verify Bootstrap JS is loaded
 * 2. Check carousel HTML structure
 * 3. Ensure images exist and paths are correct
 * 4. Check browser console for errors
 */


// ===== Issue 4: Mobile Responsiveness =====
/**
 * SOLUSI:
 * 1. Add viewport meta tag in header.tpl:
 */
<meta name="viewport" content="width=device-width, initial-scale=1.0">

/**
 * 2. Test in Chrome DevTools (F12 > Toggle Device Toolbar)
 * 3. Check media queries in CSS
 */
