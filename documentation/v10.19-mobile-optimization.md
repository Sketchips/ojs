**Logo & Text "Jurnal Riptek"** (NAIK)

- Sekarang lebih tinggi dalam header

#### 2. Code Cleanup & Optimization

**Removed Duplicates:**
1. ❌ Duplicate mobile header positioning in `@media (max-width: 768px)`
2. ❌ Redundant page-specific rules (`.pkp_page_index`, `.pkp_page_about`)
3. ❌ Duplicate login/register mobile positioning
4. ✅ Consolidated to single source of truth in `@media (max-width: 767px)`

**Simplified Login/Register Pages:**
- Hanya override positioning yang berbeda
- Inherit semua base mobile styles
- Reduced dari ~25 lines ke ~6 lines per page
