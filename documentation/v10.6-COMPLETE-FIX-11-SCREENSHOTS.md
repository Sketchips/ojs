## Technical Details

### Bootstrap 3 Grid Escape Strategy
**Problem:** Bootstrap 3's `.col-*` classes force width constraints that prevent horizontal layout

**Solution (v10.6 - AGGRESSIVE):**
```css
/* Target ALL Bootstrap grid elements */
.main-content-area .row,
.main-content-area [class*="col-"],
.main-content-area .container,
.main-content-area .container-fluid,
.about-content-wrapper .row,
.about-content-wrapper [class*="col-"] {
    width: 100% !important;
    max-width: 100% !important;
    margin: 0 !important;
    padding: 0 !important;
    float: none !important;
    display: block !important;
    flex: 0 0 100% !important;            /* Force full width in flex */
    position: static !important;          /* Remove any positioning */
}

/* Remove max-width constraints */
.info-section,
.journal-description,
.about-content-wrapper > * {
    max-width: none !important;           /* TRUE horizontal - no limit */
    width: 100% !important;
    float: none !important;
    position: static !important;
}
```

**Why This Works:**
1. **Targets all grid classes** with `[class*="col-"]` selector
2. **Forces static positioning** to break out of grid context
3. **Removes all padding/margin** that Bootstrap adds
4. **Sets flex: 0 0 100%** for flexbox containers
5. **Eliminates max-width** to allow true horizontal expansion
