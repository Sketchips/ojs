# v10.18: Mobile Header Fix - Home & About Pages

## Date: 2025-11-05

## Problem
Berdasarkan screenshot yang diberikan, pada halaman Home dan About di tampilan mobile:
1. Header terpotong di bagian atas (keluar dari viewport)
2. Logo dan navbar-toggle bertumpuk/overlap
3. Text "Jurnal Riptek" tidak terlihat dengan baik

## Solution Implemented

### Changes Made to `styleSheet.css`

#### 1. Section around Line 280-330 (Primary Mobile Fix)
**Previous Code:**
- Header positioned at `top: 0`
- Navbar-toggle using `transform: translateY(-50%)`
- Logo positioned at `left: 70px` with center transform

**New Code (v10.18):**
- Header moved down: `top: 15px` (memberi jarak dari top viewport)
- Navbar-toggle: `top: 18px` (fixed position dari header top)
- Logo: `left: 80px`, `top: 8px` (lebih ke kanan, tidak overlap dengan toggle)
- Removed `transform: translateY(-50%)` untuk positioning lebih presisi
- Added specific rules for `.pkp_page_index` dan `.pkp_page_about`

#### 2. Section around Line 1740-1800 (Secondary Mobile Fix)
**Previous Code:**
- Header at `top: 0`
- Logo at `left: 180px`, `top: 10px`
- Body padding `71px`

**New Code (v10.18):**
- Header moved down: `top: 15px`
- Logo adjusted: `left: 80px`, `top: 8px` (consistent spacing)
- Body padding increased: `86px` (accommodate moved header)
- Navbar-toggle: `top: 18px` (consistent positioning)

## Key Improvements

1. **Header Visibility**: Header sekarang visible di dalam viewport (tidak terpotong)
2. **No Overlap**: Logo dan navbar-toggle tidak lagi bertumpuk
3. **Consistent Spacing**: Spacing yang konsisten antara toggle dan logo (80px - 15px = 65px clearance)
4. **Proper Alignment**: Semua elemen aligned dengan baik di dalam header container
