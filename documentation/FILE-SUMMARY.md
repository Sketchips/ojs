## 🎯 Quick Start Commands

### Preview Demo (PowerShell)
```powershell
# Navigate to folder
cd d:\0-tugas-IK-D\projek-gabut\ojees\ojs-docker

# Option 1: Python server
python -m http.server 8000

# Option 2: PHP server
php -S localhost:8000

# Then open: http://localhost:8000/demo-modern-theme.html
```

### Copy Files to OJS (PowerShell)
```powershell
# Copy CSS
copy modern-ojs-theme.css ojs\public\

# Copy JS
copy modern-ojs-theme.js ojs\public\

# Restart Docker (if needed)
docker-compose restart
```

### Clear OJS Cache
```powershell
# Inside OJS container
docker-compose exec ojs php tools/rebuildSearchIndex.php
```

## 🎨 Customization Examples

### Change Primary Color
```css
/* Edit modern-ojs-theme.css, line ~50 */
:root {
    --primary-blue: #YOUR_COLOR;
    --gradient-primary: linear-gradient(135deg, #COLOR1 0%, #COLOR2 100%);
}
```

### Change Carousel Height
```css
/* Edit modern-ojs-theme.css, line ~450 */
.carousel,
.carousel img {
    height: 500px !important;  /* Change from 600px */
}
```

### Change Search Position
```css
/* Edit modern-ojs-theme.css, line ~300 */
.navbar-form {
    right: 200px !important;  /* Adjust value */
}
```
