# v10.20: Mobile Header & Media Query Fix

**Date**: 6 November 2025  
**Version**: v10.20  
**Status**: ✅ COMPLETED

---

## Problem Identified

1. **Media Query Conflict**: `@media (max-width: 991px)` was applying to mobile (≤767px) instead of just `@media (max-width: 767px)`
2. **Header Position**: Header was at `top: 15px` instead of `top: 0`
3. **Logo Position**: Logo and text needed to move UP and RIGHT
4. **Body Padding**: Inconsistent padding (86px vs 71px)

---

## Solutions Applied

### 1. Fixed Media Query Hierarchy

**Before:**
```css
@media (max-width: 991px) { ... }  /* ❌ Includes mobile */
@media (max-width: 992px) { ... }  /* ❌ Includes mobile */
```

**After:**
```css
@media (min-width: 768px) and (max-width: 991px) { ... }  /* ✅ Tablet only */
@media (min-width: 768px) and (max-width: 992px) { ... }  /* ✅ Tablet only */
@media (max-width: 767px) { ... }  /* ✅ Mobile only - isolated */
```

### 2. Mobile Header Positioning (≤767px)

| Element | Position | Notes |
|---------|----------|-------|
| **Header** | `top: 0` | Di atas viewport (fixed) |
| **Toggle** | `left: 8px, top: 12px` | Dalam header |
| **Logo+Text** | `left: 95px, top: 5px` | Geser kanan & naik |
| **Body** | `padding-top: 71px` | Match header height |

### 3. Responsive Logo & Text

**Logo Container:**
- Display: flex, horizontal layout
- Height: 50px (consistent)
- Proper spacing between logo and text

**Text "Jurnal Riptek":**
- Font-size: 16px (readable on mobile)
- White-space: nowrap (no wrapping)
- Line-height: 1.2 (compact)
